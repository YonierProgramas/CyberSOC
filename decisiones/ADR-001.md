# ADR-001 — Aplicación de escritorio con Electron y React

## Contexto

CyberSOC Defender requiere una interfaz de escritorio para Windows 10/11 x64 que permita seleccionar archivos, observar el progreso, consultar evidencias e interactuar con el Copilot. La interfaz debe permanecer separada de la persistencia, los secretos y el análisis de archivos. El diseño distingue renderer, proceso principal y motor Python hijo.

Fuentes: decisiones D1 y D2 de [00-ESTADO.md](../00-ESTADO.md), [resumen general](../01-resumen-general.md) y secciones de estructura y seguridad del [plan S0](../sprints/sprint-00-foundation/plan.md).

## Decisión

Se propone utilizar Electron con electron-vite y TypeScript en modo `strict`. El renderer empleará React y CSS propio, sin una biblioteca de componentes al inicio. React se adopta como tecnología de interfaz; no implica incorporar el conjunto MERN.

El proceso main compondrá los servicios del Core y los adaptadores de Electron. `src/core/` no importará `electron`; esta restricción se comprobará mediante ESLint. La estructura separará `main`, `preload`, `renderer`, `shared` y `core`.

La ventana tendrá `contextIsolation: true`, `sandbox: true` y `nodeIntegration: false`, CSP estricta, navegación bloqueada y denegación de nuevas ventanas. El preload expondrá operaciones explícitas mediante `contextBridge`; main validará sus entradas con zod. El renderer no realizará conexiones externas ni accederá directamente al sistema de archivos o a secretos almacenados.

## Alternativas consideradas

Las fuentes no registran una comparación formal con otros frameworks de escritorio o de interfaz. Por tanto, este ADR no atribuye al equipo una evaluación o un descarte que no estén documentados. Sí establecen el uso inicial de CSS propio y la exclusión de una biblioteca de componentes en esta etapa.

## Consecuencias

- La presentación y la lógica de aplicación quedan separadas y pueden verificarse mediante pruebas de sus interfaces.
- El acceso a capacidades del sistema pasa por main y exige mantener un puente IPC limitado y validado.
- El equipo debe comprobar el endurecimiento de todas las ventanas y el cierre del proceso Python, además de typecheck, lint y pruebas.
- La aceptación académica de React continúa pendiente de confirmación, según el estado del proyecto.
